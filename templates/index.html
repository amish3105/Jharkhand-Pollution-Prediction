Open-Meteo Air Quality API

Provides hourly pollutant and AQI model output for coordinates. This project uses its current-condition values and recent/forecast hourly series.

Read API documentation ↗
CAMS atmospheric modelling

Open-Meteo's air-quality service is based on atmospheric composition modelling. A grid-cell estimate may not represent a nearby street or industrial facility.

Methodology & limitations

Designed for transparency and academic project review.

CoverageSelected Jharkhand district/city coordinates. They are not guaranteed to align with official monitoring stations.
Current valuesRetrieved from the live Open-Meteo air-quality endpoint. Values are model-based estimates.
AQI scaleUS AQI returned by the provider; not the India-specific CPCB AQI.
ForecastProvider-generated hourly forecast; this version does not claim a separately trained proprietary ML model.
Water pollutionCommunity reports can be submitted, but verified water-quality measurements are not included because a reliable live district-level source has not been configured.
Data outageIf the API is unavailable, the site shows an unavailable/error state instead of inventing readings.
PrivacyComplaint data is stored locally in SQLite. Optional contact information is stored with the report; deploy only with an appropriate privacy notice and access controls.
JHARKHAND / AIR · Pollution Intelligence Platform · Data is provided for information and education, not as official regulatory, medical or emergency advice. Always verify critical readings with official sources. Open-Meteo and OpenStreetMap attribution applies.
